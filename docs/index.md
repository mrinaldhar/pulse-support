# Pulse

Pulse is a calm, shared home app: kitchen, calendar, reminders and music in one place.

## Contact

Email **webmaster.mrinal@gmail.com** and include:

- what you were doing,
- what happened,
- what you expected,
- your iPhone/iPad model and iOS version,
- a screenshot if useful.

We aim to reply within a couple of days.

## Using the beta

1. Install **TestFlight** from the App Store.
2. Accept the **Pulse** invitation.
3. Install the latest build.
4. Take a screenshot in the app and choose **Send** to attach it to feedback, or use **Household → Send feedback**.
